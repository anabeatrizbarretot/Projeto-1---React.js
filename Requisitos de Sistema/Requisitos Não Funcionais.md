# Requisitos Não Funcionais

| **ID** | **Requisito**         | **Descrição**                                                                                                    |
| ------ | --------------------- | ---------------------------------------------------------------------------------------------------------------- |
| RNF01  | Tecnologia            | O sistema deve ser desenvolvido utilizando React.js.                                                             |
| RNF02  | SPA                   | O sistema deve funcionar como uma Single Page Application, sem precisar recarregar a página durante a navegação. |
| RNF03  | Comunicação com API   | O sistema deve utilizar AJAX para realizar as requisições à API.                                                 |
| RNF04  | API JSON              | O sistema deve utilizar uma API JSON aberta para obter os dados das receitas.                                    |
| RNF05  | Hook React            | O sistema deve utilizar o `useReducer` para auxiliar no gerenciamento dos estados da aplicação.                  |
| RNF06  | Biblioteca externa    | O sistema deve utilizar uma biblioteca externa junto ao React.js, como o React Bootstrap.                        |
| RNF07  | Responsividade        | A interface deve se adaptar a diferentes tamanhos de tela, como computadores, tablets e celulares.               |
| RNF08  | Organização do código | O código deve ser dividido em componentes para facilitar a organização e manutenção do sistema.                  |
| RNF09  | GitHub                | O projeto deve possuir um repositório público no GitHub.                                                         |
| RNF10  | Usabilidade           | O sistema deve possuir uma interface simples e fácil de utilizar.                                                |
| RNF11  | Desempenho            | O sistema deve apresentar os resultados das pesquisas sem realizar recarregamentos desnecessários da página.     |
| RNF12  | Tratamento de erros   | O sistema deve tratar possíveis erros de conexão ou indisponibilidade da API.                                    |
